# AstralGalaxyMusicPlayer

## 1. 部署与构建说明

### 1.1 运行环境要求
* 操作系统: Windows 10/11 (x64)。
* 运行库: Microsoft Edge WebView2 运行时。

### 1.2 构建指令
项目采用标准 Tauri 构建管线，生产环境发布指令如下：
```bash
# 安装依赖
npm install

# 执行生产环境构建
npm run tauri build
```
